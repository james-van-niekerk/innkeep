# innkeep

A TUI that wraps Homebrew — save your installed packages/config as a user profile, then reinstall and maintain a system from it. Also planned: a Nix-like declarative option for managing configs and installs.

Built with [OpenTUI](https://opentui.com) and [Bun](https://bun.com).

## Install dependencies

```bash
bun install
```

## Run

```bash
bun run index.tsx
```

Press `q` to quit.
